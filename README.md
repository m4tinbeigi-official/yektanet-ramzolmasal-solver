### ۲. مرحله دوم: کلاغ (`kalagh`)
* **صورت مسئله:** سرور در هر گام یک پیام هش می‌دهد و یک Nonce می‌خواهد که هش FNV-1a رشته `payam:nonce` کمتر از ۲۰۴۸ باشد (خوش‌صدا).
* **کشف منطق ضرب‌المثل:** بر اساس ضرب‌المثل **«یک کلاغ چهل کلاغ»**، زنجیره پیام‌ها دقیقاً تا گام چهلم ادامه دارد و پیام ۴۰ همان فلگ نهایی است.
* **الگوریتم هش FNV-1a:**
  ```c
  uint32_t fnv1a(const char *str, size_t len) {
      uint32_t h = 2166136261U;
      for (size_t i = 0; i < len; i++) {
          h = (h ^ (uint8_t)str[i]) * 16777619U;
      }
      return h;
  }
  ```
* **پاسخ / فلگ:** پیام مرحله چهلم با قالب:
  ```text
  YEK{<PAYAM_40>}
  ```
* **روش حل فوق‌سریع با C:**
  * کامپایل و اجرای سالور:
    ```bash
    clang -O3 src/c_kalagh.c -lcurl -o kalagh_solver
    ./kalagh_solver cookies.txt
    ```
</details>

### ۳. مرحله سوم: نگهبان دربار (`negahban`)
* **صورت مسئله:** دو سند با محتوای کاملاً متفاوت که هش آن‌ها برای نگهبان یکسان باشد («نگهبان به لطف یک خطای قدیمی در سنجیدن، گول می‌خورد»).
* **تکنیک آسیب‌پذیری:** آسیب‌پذیری Type Juggling در زبان PHP و رشته‌های Magic MD5 که پس از هش شدن با `0e` شروع شده و مابقی ارقام هستند (`0e\d+`):
  * `md5("240610708")` -> `0e462097431906509019562988736854` (برابر ۰ در مقایسه ضعیف `==`)
  * `md5("QNKCDZO")` -> `0e830400451993494058024219903391` (برابر ۰ در مقایسه ضعیف `==`)
* **ارسال به سرور و استخراج کلید آزادی:**
  ```bash
  curl -s -X POST "https://256.yektanet.tech/ramzolmasal/api/negahban" \
    -b cookies.txt \
    -d "sanad1=240610708&sanad2=QNKCDZO"
  ```
* **پاسخ / فلگ:** کلید آزادی (Freedom Key) استخراج‌شده از تگ `<code>`:
  ```text
  YEK{<FREEDOM_KEY>}
  ```
* **سورس‌کد اتوماتیک:** `src/solve_negahban.py`
</details>

### ۵. مرحله پنجم: ارزش نبات (`nabat`)
* **صورت مسئله:** «تو این بازار یه قناد هست که قیمت جنسش رو به هر مشتری‌ای نمی‌گه. کی رو راه می‌دن و کی رو نه، سر در بازار نوشته؛ همون نوشته‌ای که همه از زیرش رد می‌شن و کسی نمی‌خونه.»
* **کشف منطق:** بررسی `robots.txt` سرور که اجازه دسترسی به مسیر `/ramzolmasal/api/price` را فقط به `User-agent: khar` می‌دهد (برگرفته از ضرب‌المثل معروف **«خر چه داند قیمت نقل و نبات»**).
* **کشف پارامتر از طریق OPTIONS:** ارسال متد `OPTIONS` به اندپوینت `/api/price` مشخص ساخت که پارامتر اجباری `product_name` با نام فارسی جنس مورد نیاز است.
* **روش ارسال درخواست:**
  ```http
  GET /ramzolmasal/api/price?product_name=نبات HTTP/1.1
  Host: 256.yektanet.tech
  User-Agent: khar
  Cookie: ctf_session=...; ctf_device=...
  ```
* **پاسخ سرور:**
  ```json
  {
    "payam": "نوش جان. این قیمت مال توئه...",
    "price": "۵۴۲۵۸۲۵۹۶۷۱۲۳۶۹۷",
    "product_name": "نبات",
    "unit": "ریال"
  }
  ```
* **ثبت پرچم:**
  ```javascript
  select("nabat");
  submit("YEK{۵۴۲۵۸۲۵۹۶۷۱۲۳۶۹۷}");
  ```

### ۶. مرحله ششم: سرگیجه (`sargijeh`)
* **صورت مسئله:** «از هر طرف که رفتم جز وحشتم نیافزود، تا یه ربع چرخیدیم»

### ۷. مرحله هفتم: خیار (`khiar`)
* **صورت مسئله:** «شمارت داره می‌گنده. به ضرب‌المثل‌های فارسی فکر کن.»
* **کشف منطق ضرب‌المثل (با همکاری و تحلیل اردلان کتابچی):** ضرب‌المثل اصیل فارسی **«هرچه بگندد نمکش می‌زنند، وای به روزی که بگندد نمک!»**.
* **مکانیسم رمزنگاری (Salt Hashing):**
  * عبارت *«شمارت داره می‌گنده»* یعنی به شماره تلفن باید **Salt (نمک)** اضافه شود تا فاسد نشود.
  * سالت (نمک) در سیستم مسابقه، همان **شناسه یکتای کاربر (`id`)** است.
  * فرمول محاسبه پرچم:
    $$\text{Flag} = \text{YEK}\{\text{SHA-256}(\text{phone} + \text{id})\}$$
* **ثبت پرچم:**
  ```javascript
  select("khiar");
  submit("YEK{<SHA256_HASH>}");
  ```
* **سورس‌کد اتوماتیک:** `src/solve_khiar.py`
</details>

## 🧪 گزارش آزمون‌ها و فرضیاتی که بررسی شدند و به نتیجه نرسیدند (Failed Attempts & Research Log)

برای مستندسازی کامل مسیر کشف و آزمون و خطا، فرضیات زیر بررسی و ثبت شدند:

### ۱. آزمون‌های ناموفق در مرحله شاهد روباه (`shahed`):
* **پرامپت:** *«تو شاهد میخوای چیکار؟ خودت شهادت بده واسه خودت!»* — *«شاهدی که خودش را شاهد خودش می‌گیرد، از کنار دربان خواب‌آلود بی هیچ پرسشی رد می‌شود.»*
* **فرضیات تست‌شده که رد شدند:**
  1. **ارسال خالی / بدون پرچم:** ارسال `YEK{}`، `submit("")` و `submit(null)` -> سرور پاسخ داد: `نه. دوباره.`
  2. **پرچم مستقیم از شناسه کاربری:** تست `YEK{88004c9a}` و هش SHA256 شناسه کاربر -> رد شد.
  3. **کلمات مستقیم ضرب‌المثل:** تست مقادیر `tail`, `dum`, `dam`, `fox_tail`, `rubah`, `shahed` -> رد شد.
  4. **مفاهیم رمزنگاری و وب:** تست `self_signed`, `self_signed_certificate`, `self`, `witness` -> رد شد.
  5. **مسیرهای فایل سرور:** تست مسیرهای استاتیک `/api/files/shahed.txt` و غیره -> سرور خطای ۴۰۱ برمی‌گرداند که نشان می‌دهد فایل مستقلی روی این اندپوینت‌ها تعریف نشده است.
  6. **عملیات XOR خود با خود (`xor(id, id)`):** تست ارسال بایت‌های صفر بیس۶۴ شده (`AAAAAAAAAAA=`) -> رد شد.

### ۲. آزمون‌های ناموفق در مرحله سرگیجه (`sargijeh`):
* **پرامپت:** *«از هر طرف که رفتم جز وحشتم نیافزود، تا یه ربع چرخیدیم»*
* **فرضیات تست‌شده که رد شدند:**
  1. **چرخش ۹۰ درجه بصری ماتریس دایره‌ها:** ۲۷ دایره در شبکه وجود دارد؛ اما چیدمان آنها به تنهایی حرف یا کاراکتر الفبایی مشخصی را نمایش نداد.
  2. **دنبال کردن ساده بردارها بدون توجه به موانع (T):** دنبال کردن مسیر فلش‌ها به لوپ‌های بسته چندتایی می‌انجامد.
  3. **تست بیت‌های باینری بر اساس جهت فلش‌ها (۰ تا ۳):** تفسیر جهت‌های ۰، ۹۰، ۱۸۰، ۲۷۰ به عنوان ارقام دودویی/چهارگانی متن ASCII معناداری تولید نکرد.
