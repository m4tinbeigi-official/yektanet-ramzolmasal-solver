## 📋 خلاصه روش حل هر مرحله

### 1. تاتی تاتی (tati-tati)
- **پرچم:** `YEK{YektaNet}`
- **روش:** احراز هویت اولیه و ثبت پاسخ مرحله ورودی

### 2. شاهد روباه (shahed)
- **روش:** آسیب‌پذیری JWT کلاینت با `alg: none` و جعل نقش `admin`

### 3. کلاغ (kalagh)
- **روش:** ماینینگ Nonce با الگوریتم FNV-1a تا کلاغ چهلم

### 4. نگهبان دربار (negahban)
- **روش:** PHP Type Juggling با برخورد جادویی (`240610708` و `QNKCDZO`)

### 5. ارزش نبات (nabat)
- **روش:** هدر `User-Agent: khar` و استخراج قیمت از API

### 6. سرگیجه (sargijeh)
- **پرچم:** `YEK{welcome_to_tanzolmasal}`
- **روش:** چرخش ۹۰ درجه ماتریس SVG و اجرای Brainfuck

### 7. خیار (khiar)
- **روش:** `SHA-256(phone + user_id)` با salt اختصاصی هر کاربر

### 8. یاایکس (ya-x)
- **پرچم:** `YEK{8b20d2e007c740e35428d1bbdd964654}`
- **روش:** XOR بایتی `chap.bin` با آیکون دست ۳۲×۳۲

### 9. کیمیاگر (kimiagar)
- **روش:** WebSocket + فیلتر کلمات طلایی (SHA-256 Base64 شروع با `Au`)

### 10. دیوار به دیوار (pelak)
- **روش:** تونل شبکه به همسایه (254.yektanet.tech) و شکستن ZIP
